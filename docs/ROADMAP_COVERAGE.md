# Roadmap coverage and remaining work

## Implemented

- Python/Streamlit prototype with language, crop, district, season, stage and soil selectors.
- V0–V10 library, cumulative quality ladder, compressed instructions, conservative context reduction, compact JSON, two-call V9 and capped combined V10.
- Localised headings and disclaimers; no dosage, chemical-mixing or banned-product recommendations in guarded prompt versions.
- Provider input/output/total usage, configured price calculation, latency and comparison savings.
- Truncation flags and compact schema validation, with raw failed responses preserved.
- Clear credential-free demo with unmeasured metrics.
- 18 test queries across three languages; vague, unsafe, injection and out-of-scope cases.
- 10 aligned language-token snippets; fixed six-criterion scoring rubric.
- Resumable batch runner, manifests/hashes, repeats, separate blind scores/mapping, validated summaries and interactive charts.
- Run export/downloads, automated accounting/UI tests, report/presentation/demo templates.

## Requires real-world inputs or review

- Faculty approval and exact demonstration slot.
- Valid API credentials, accessible model and current verified pricing.
- Context/source verification by local agricultural specialists.
- Fluent-speaker verification of test translations, snippets and generated Kannada/Hindi.
- Live full batch, repeated trials, human scores and failure review.
- Measured findings, final report text, actual screenshots/charts and recorded rehearsal.

## Optional or outside scope

V11 caching is not implemented. Fine-tuning, image diagnosis, live weather/markets, voice and large retrieval systems remain future work. A deployable public production service, authentication and production monitoring are not included.

## Suggested three-week execution

Week 1: confirm faculty framing; configure key/model; verify context/translations; freeze rubric; review prompts and run anchors.
Week 2: run language counts; freeze settings; collect full/repeated outputs; blind/domain/language-score; inspect safety; generate charts.
Week 3: complete report/presentation with actual findings; record/rehearse the demo; review references, secrets and submission requirements.
