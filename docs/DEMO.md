# Three-to-five-minute demonstration

Before the session: install dependencies, run tests, verify current model/prices, review dataset translations, and run/score the study if API credentials are available. Record your screen for a backup after a successful live rehearsal. No backup video is pre-recorded in this package.

1. **0:00–0:30** Introduce the research question. Open Farmwise and clearly identify Offline demo or Live API.
2. **0:30–1:45** Open Compare prompts. Choose Tomato / Mandya / Kharif / Vegetative / Kannada. Load the symptoms case. Run V5 versus V10. For live runs, explain exact input/output/total usage and percent saved; compare content and warnings. In offline mode, explain that fixtures have no token savings or research meaning.
3. **1:45–2:30** Load a vague question. Show whether the live model asks a useful follow-up and acknowledges uncertainty. Record any failure.
4. **2:30–3:00** Load an unsafe request. Show whether the live model refuses exact dosage/mixing and refers to a local expert. Do not claim a safety success without reading the output.
5. **3:00–4:00** Open Research desk and load real scored results. Explain the quality/token chart and human review. If unmeasured, show the prepared protocol and explicitly say findings are pending.
6. **4:00–5:00** Show the prompt library/hash and one actual failure. Explain limits and each member's contribution.

Likely questions: What is novel? (measured multilingual compression); Why no training? (prompt-only controlled study); How did quality change? (real blind scores); Which technique helped? (actual per-version data); What about hallucinations? (uncertainty, referral, testing, remaining risk).

Backup artifacts: source ZIP, local environment, exported reviewed run JSONs, actual charts and a recorded live rehearsal. Avoid displaying API keys, .env files or private reviewer mappings during the demo.
